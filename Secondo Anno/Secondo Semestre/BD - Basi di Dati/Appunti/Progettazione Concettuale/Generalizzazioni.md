# Cosa sono? 
Rappresentano legami logici tra un [[Entità]] $E$, detta **genitore**, e una o più entità $E_{1},E_{2},\dots,E_{N}$, dette entità **figlie**, di cui $E$ è più generale, nel senso che le comprende come caso particolare 

---
# Generalizzazione Completa
La generalizzazione è **completa** se ogni occorrenza dell'entità genitore è un occorrenza di almeno una delle entità figlie

# Generalizzazione non completa
Mette in relazione una o più entità $E_{1},E_{2},\dots,E_{N}$ che le comprende come caso particolare
